# Learning Courses Platform (Frontend)

This repository contains the frontend client for the Learning Courses platform. It is a web application built with [Next.js](https://nextjs.org/) and React.

The backend is available in a separate repository: [learning-courses](https://github.com/UniversityProjectKNU/learning-courses).

## Tech Stack

- **Framework**: Next.js & React (App Router)
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Tooling**: Biome (Linter and Formatter)
- **UI Components**: Material UI (MUI) combined with custom components
